Which data, used where

Every pixel in the tool comes from the NASA archive. No image or data point is generated. This page shows which data set is used for what. It also lists the ones we downloaded but do not use yet.

01List We ask IRSA which exposures cover the position. The answer is a few hundred kB.
02Read only what is needed From each 66 MB file we read only the header and the pixel rows, by byte range: about 80 kB per exposure.
03Package We write the exposures to one package with their times, wavelengths and astrometry (position data).
04Compute in the browser Stacking, differences, spectra and measurements run on the page; no server is needed.

The downloaded offline archive

We also downloaded everything on the challenge's resources page to disk (about 80 GB). The tool's results do not depend on this archive; the tool reads the same exposures from the NASA archive itself. Below is the current state of each folder.

Folder Contents Size Status
01_nasa_spherex 3,902 IRSA cutouts of the five test targets (Barnard 358, ε Indi B 458, WISE 0855 258, RW Aur 335, R Dra 2,493), IRSA tutorials, archive documentation. 15 GB in use The tool can read these cutouts with no network. We measured the photometry again with the real PSF from the WISE 0855 cutouts.
02_nasa_gaia Gaia DR3 catalogues around the test targets (0.15°). 8 MB backup The tool queries the same catalogue itself.
03_csa_neossat NEOSSat tutorial, supporting documents, two sample days from 2024 (380 FITS). 2.1 GB not used We looked at it: it is visible light, and no frame is closer than 39° to any of our fields. It is not part of any result.
04_wiseview CatWISE2020 and AllWISE catalogues, WiseView pages. 27 MB not used The tool uses the single-exposure tables instead.
05_y_dwarfs 16,135 SPHEREx cutouts: SMDET-1 and 10 cold dwarfs in the Galactic plane (six detectors), 34 Y dwarfs off the plane (D4–D6). Kirkpatrick 2024 tables (40 Y dwarfs within 20 pc), three papers. 61–63 GB in use The fields of 42 dwarfs were built from these cutouts. In the blind test the cold filter, not told where to look, raised an alarm at 37 of the 42 dwarfs. At empty positions the rate is 4%, and there are 4.8 false alarms per field on average.
06_sky_background 100 channels of the SPHEREx DR1 all-sky HiPS cube, the AllWISE colour HiPS, and 8192-pixel sphere images made from them. 817 MB in use The VR background (4.57 µm), the site background (three colours), and the 100 channel maps you can step through in VR.
07_web_vendor A-Frame 1.8, three.js r187 74 MB not used The tool comes with its own three.js r160.
