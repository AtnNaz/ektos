How it works

The same patch of sky on two dates. Anything that moved stands out.

Ektos is a blink and stereo comparison tool for the SPHEREx infrared all-sky survey. You enter a coordinate, and it compares how that spot looked on different dates. The thirteen short steps below show how it works and where it stops.

A · earlier epoch B · later epoch live or selected 13 steps · about three minutes

01

No two frames in the same colour

SPHEREx photographs the whole sky every six months, in 102 colours. Its linear variable filter changes colour from one end to the other. So each exposure (a single shot) sees the same point at a different wavelength, or colour. There are never “two frames in the same colour” to compare.

02

Reading only the bytes we need

Each file in the archive is 66 MB. The official cutout service sends 3.95 MB for one cutout, because it adds a 3.86 MB PSF table. From the public S3 bucket, Ektos reads only the header and the pixel rows it needs. It asks for them by HTTP byte range: about 80 kB per exposure.

03

Making frames we can compare

You choose a wavelength window. The tool takes every exposure of one visit that falls inside it. It subtracts the sky background, puts them on one common grid with north up, and averages them. Exposures with less noise count more (inverse-variance weights). The result is one frame per visit, all seen through the same window.

04

Blink: two epochs in turn

The tool shows two epochs (two dates) one after the other. Stars that stayed put do not move; an object that changed place jumps. The frames here are real: Luhman 16, a pair of brown dwarfs 2 pc away. In this window we measured a shift of 2.5″ in one year; the catalogue model says 2.7″.

05

Difference: B minus A

We subtract the first frame from the second. Light that is only in A shows red; light that is only in B shows blue. An object that moved becomes a red–blue pair.

06

Stereo: an idea from 1901

The left eye sees A, the right eye sees B. Stars that stayed put merge into one flat plate. An object that moved floats in front of the plate or behind it. This is the stereo comparator that Carl Pulfrich built at Zeiss in 1901; Max Wolf found asteroids with it. The blink comparator came in 1904, and Tombaugh found Pluto with blink in 1930.

LimitThis only works for shifts of a few arcseconds. WISE 0855 moved about 130″ between 2010 and 2026. A shift that large does not merge; you see a double image. The tool opens the pair in a VR headset (HTC Vive Pro). We have not yet confirmed in the headset that the object separates in depth. We have not yet measured whether stereo beats blink either.

07

Removing ordinary stars by their colour

R = W2s − k · W1s

We call this the cold dwarf filter. W2s is the 4.0–5.0 µm image and W1s is the 3.0–3.8 µm image. k is the median brightness (flux) ratio of the field’s own stars. Ordinary stars cancel out. A cold object, bright only at 4–5 µm, stays.

09

Parallax: from a wobble to a distance

On top of its straight motion, the object wobbles once a year, because Earth goes around the Sun. This wobble is called parallax; its size gives the distance. For WISE 0855, WISE and SPHEREx together give 0.502 ± 0.038″. That is about 2.0 pc (the published value is 2.28 pc).

A control for every claim

We repeat every measurement at empty positions or on control stars. If the target stands outside the controls, the result means something. If it sits among them, it does not.

13

What we do not claim

  • That we discovered a new object.
  • That we confirmed SMDET-1.
  • That SPHEREx can see Planet Nine.
  • That stereo is better than blink, before we run the experiment.
  • That SPHEREx alone measures parallax for faint objects.
  • That the machine observer’s numbers hold for human observers.

The measurements on this page come from the repository’s README. It describes the full method and its limits. You can try the rest yourself in the tool.
